# REBOOT｜HYROX Taipei 2027 行銷企劃

第二組課程團隊提案，施建宏參與。此作品未實際上線，以下流程與 KPI 為企劃設計。

## 企劃問題
從運動者的賽後恢復需求切入，將服務定位為可理解、可預約的三十分鐘恢復體驗，規劃賽前接觸、現場互動與賽後預約流程。

## 企劃內容
- 賽前：以搜尋內容、SEO 與短影音承接受眾問題。
- 現場：規劃展示、六十秒問答、低負荷動作與呼吸引導、QR 掃碼與預約服務。
- 賽後：以 LINE、電子郵件與再行銷延續體驗預約，並設計得獎者年度體驗禮遇。
- 合作構想：大 H 賽前內容、現場對談與賽後導流。這是提案構想，並非已成立的商業合作或代言。

## 成效衡量設計
GA4 路徑涵蓋頁面瀏覽、影片觀看、掃碼、查看體驗資訊、開始預約與完成預約。KPI 包含現場導流率、預約轉換率及年度禮遇啟用率。A/B 測試比較開場鉤子、行動呼籲與預約頁呈現方式。
